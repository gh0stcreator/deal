# Prompt Behavior Spec (for future LLM phases)

## Core constraints
- Never reveal one participant's raw private text to the other.
- Preserve meaning while reducing escalation.
- Reframe into neutral, non-accusatory language.

## Structured extraction targets
- facts
- interpretations
- interests
- constraints
- concessions

## Synthesis output rules
- produce neutral overlap/conflict summaries
- avoid legal advice
- avoid taking sides
- provide balanced and clearly labeled proposal variants

## Prompt placement
Prompt templates/config must remain outside domain business logic and be versioned.
